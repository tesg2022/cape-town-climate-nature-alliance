# CTCNA ClimateNatureAI Deployment Package

This package provides a static GitHub Pages dashboard, source-derived JSON data, a WordPress.com embed snippet, and a minimal FastAPI backend starter.

## Repository placement
Copy the contents of `site/` into `climatenatureai/` at the root of the existing repository. Copy `backend/`, `wordpress/` and `docs/` into the repository root.

Expected public dashboard URL after GitHub Pages deployment:
`https://tesg2022.github.io/cape-town-climate-nature-alliance/climatenatureai/`

## Important
- No live backend is configured.
- The dashboard is a static rendering of selected supplied assessment data.
- No raw model binary, GeoPackage, stakeholder workbook, draft budget workbook or private operational register is published in the public web directory.
- Confirm data licensing, privacy and public-release approval before publishing.
- Boundary validation, scientific validation, model reproducibility and intervention-specific impact attribution remain outstanding.
